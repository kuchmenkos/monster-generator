# Булала · база, батлы и мастерская

Новая оболочка на Three.js находится на `/` с тремя вкладками: **База**, **Батлы**, **Мастерская**. Старый Pixi-прототип сохранён на `/legacy.html`.

## Запуск

```sh
npm install
npm run dev
```

Открыть http://127.0.0.1:5173 (или адрес, который напечатает Vite). Маршруты: `#/base`, `#/battles`, `#/workshop`.

```sh
npm test       # ДНК, геометрия, экономика, прожарка, батлы
npm run build
npm run preview
```

## Вкладки

### База (главная)

Минималистичный mobile-first экран: булала чуть выше центра. Зажми 1с — блобы вокруг **головы** (Sims radial-drag); взгляд и наклон тела следуют за наведённой кнопкой. Уход с FX (душ/пена, кормление, 3 варианта поглаживания); грязь/мухи/смрад при низких needs. Внизу — peek-коллекция с WebP-превью.

### Батлы

Полный оверлей-плеер: пипки раундов, гонг + карточка «РАУНД N», прожектор на спикера, караоке-субтитры, мик-дроп, голосование в шите. SFX через WebAudio (переключатель в шапке).

### Мастерская

Существо на весь экран + нижний шит без вложенных скроллов: горизонтальная snap-лента вариантов, ←/→ и кнопки prev/next, живой превью на hover.

## Экономика (прототип, localStorage)

Две валюты:

- **РЕП** — на существо, только растёт (престиж, рейтинг, будущая косметика).
- **ХАЙП** — на аккаунт, тратится на боксы (1000 хайпа или заглушка $2).

Награды: победа ≈ +40 реп / +60 хайп, поражение ≈ +8 / +15, голос +5 хайпа (лимит 10/сутки), полный уход за день +25 хайпа и полная энергия. Множитель 0.4–1.6 от разницы репа (антифарм).

Стартовый хайп: 1200 (хватает на первый бокс).

## Бокс и появление

Анимация `fx/reveal.ts`: левитирующая капсула → 3 тапа с SVG-трещинами и световым пробоем → спалах/ударная волна → пружинная поява с буквами имени и лентой редкости. Пока капсула живёт, воркер уже строит меш.

## Данные

- `localStorage` ключ `bulala-save-v1` — JSON сейва (существа без PNG, батлы, хайп, страна, голоса).
- IndexedDB `bulala-media-v1` — WebP-превью 192px и кеш TTS MP3.
- Старый `bulala-collection-v1` мигрируется один раз при первом запуске (геномы сохраняются).

## ElevenLabs

В `.env.local`:

```dotenv
ELEVENLABS_API_KEY=sk_...
ELEVENLABS_VOICE_ID=optional_default
```

Провайдер для батлов запоминается в `localStorage` (`bulala-tts-provider`). Кеш аудио: `game/tts-cache.ts` (память LRU + IndexedDB), префетч следующего бара во время текущего.

## Структура (новое)

- `src/bulala/app/` — shell, router, sheet, base, battles, workshop, battle-stage, collection-sheet
- `src/bulala/game/` — state, store, economy, care, battle, roast, ranking, tts-cache
- `src/bulala/fx/` — radial, reveal, care-fx, needs-fx, sfx, geometry, needs-map
- `src/bulala/stage-core.ts` — общая Three-сцена + framing
- `src/bulala/style/` — tokens, atoms, shell, sheet, base-screen, workshop, battles, reveal, fx

Легаси `style.css` больше не импортируется (конфликтовал с layout). Генератор (`genome`, `creature` геометрия, `morphology`, …) по контракту ДНК не менялся; у creature/motion добавлены только `attention` и реакции `shiver`/`chew`.

## Границы прототипа

- Нет реальной оплаты, аккаунтов и серверного рейтинга.
- Голоса, реп и топ стран живут в браузере и легко подделываются через DevTools.
- Оппоненты батлов — боты с фиксированных seed + другие свои булалы.
- Vite-плагин голоса работает в `dev` / `preview`, не на голом статическом хостинге.
- Косметика за реп — заглушка (слоты в модели данных есть).
