# Булала · пластилиновая мастерская

Новая мастерская на Three.js находится на `/`. Старый Pixi-прототип сохранён на `/legacy.html`; его исходники, история лайков и дизлайков и Respeecher не заменены.

## Запуск

```sh
npm install
npm run dev
```

Открыть http://127.0.0.1:5173 (или адрес, который напечатает Vite).

```sh
npm test       # ДНК, вероятности, геометрия, контракт голосового API
npm run build # TypeScript + production assets
npm run preview
```

## Что работает

- Процедурная объёмная голова без рук, ног и туловища; сзади парные мягкие булочки и необязательный хвост.
- 17 категорий, 129 вариантов. Зубы, брови, разрез глаз, материал и окрас настраиваются отдельно. Дополнительные признаки раскрываются в «Ещё немного причуд».
- Общая непрерывная поверхность головы, сваренные вершины, объёмные глазницы и веки, углублённые ноздри. Булочки построены сглаженным объединением двух объёмов. Покрытия собраны из изогнутых волокон и пластин в объединённые меши; зернистость кожи — процедурная bump-текстура.
- Вращение мышью/пальцем, масштабирование, кнопки ракурсов, автоповорот, пауза; дыхание, моргание, движение взгляда, ушей и хвоста, реакция на поглаживание. Учитывается `prefers-reduced-motion`.
- Независимое переключение признаков; замочки удерживают выбранные категории при следующей генерации. Ползунок меняет асимметрию и вариации формы.
- Ссылка с полной ДНК воспроизводит и ручные изменения. Новый seed создаётся через `crypto.randomUUID`; ручной seed допускает латиницу, цифры и дефис. Нет глобального реестра или гарантии уникальности между пользователями.
- Коллекция с PNG-превью хранится в localStorage (до 48 персонажей, с обработкой переполнения); недавно просмотренные — в памяти текущей вкладки.
- Карточка PNG 1200×1500 с предпросмотром, текущим ракурсом, именем, характером, редкостью и сокращённым seed. В dev/preview скачивание идёт через обычный HTTP-ответ, совместимый с webview; последние восемь экспортов временно хранятся в памяти локального сервера. На статическом хостинге используется blob-ссылка.

## Анатомия и реакции v2

- Формы рта и зубов независимы: округлые резцы, мелкие и редкие зубы, верхние клыки, нижние бивни, акульи зубы. Зубы, дёсны и язык находятся внутри пасти.
- Разрез и глубина глаз, пять видов бровей. Форма зрачков общая; только у двухглазых существ с вероятностью 5% один зрачок отличается. Результат воспроизводится по seed.
- Раздельные покрытие, материал и окрас: кудри, дреды, лохматые пучки, длинные волосы, лепестки, чешуя; 12 палитр, полосы, розетки, пятна, светлый низ и рисунок задней части.
- Настроение: спокойное, радостное или грустное. Улыбка, крик и вздох — временные визуальные реакции с возвратом к настроению. Крик и вздох останавливают речь.
- Поглаживание вызывает улыбку и два небольших прыжка. Задняя часть реагирует затухающей инерцией на вращение камеры. При уменьшенном движении прыжки и тряска отключены.
- Белая подставка убрана; остаётся мягкая тень.
- Демо чередует 12 фраз без повторов подряд и сохраняет вручную введённый текст. Начало речи и границы слов уточняют артикуляцию, где браузер предоставляет эти события.
- Старые ссылки и коллекции мигрируют в ДНК v3 с сохранением seed, прежних признаков и голосовых привязок. Настроение является состоянием мастерской, а не генетическим признаком.
- Устаревшие превью обновляются последовательно вне видимой сцены. Перед записью перечитывается коллекция; Web Locks координирует изменения вкладок. Удалённые во время обновления существа не возвращаются.

## Редкость

Веса категорий находятся в `src/bulala/genome.ts`; сумма весов каждой категории равна 100. Семплер независим по категориям. Информационная редкость равна сумме `-log2(p)` по 17 выбранным признакам. Она сравнивается с фиксированной выборкой из 16 000 персонажей: это воспроизводимая **оценка** процентиля модели, а не статистика пользователей или коллекций. Значение «Редче X% случайных Булал» растёт вместе с редкостью. Качество геометрии и непрерывные вариации не зависят от уровня редкости.

Редчайший верхний 1% — легендарные, следующие до 8% — эпические, до 30% — редкие, остальные — необычные. Вероятность точной комбинации категорий также показана в объяснении. Непрерывные деформации, ползунок и seed в эту вероятность не входят. Ручная настройка и закреплённые признаки сравниваются со свободной генерацией.

## ElevenLabs

В существующую `.env.local` **добавить**, сохранив прежние переменные:

```dotenv
ELEVENLABS_API_KEY=your_key
# Необязательно: голос по умолчанию
ELEVENLABS_VOICE_ID=your_voice_id
```

Перезапустить Vite. Во вкладке «Голос» выбрать ElevenLabs, затем:

1. Указать Voice ID или использовать голос из окружения.
2. Либо нажать «Создать уникальный голос». Сервер получает варианты Voice Design и сохраняет первый в аккаунте ElevenLabs. Это использует квоту API и слот голоса. Привязка к seed записывается в `.bulala-voices.local` (игнорируется Git). Повторный запрос того же seed использует сохранённый голос.
3. Ввести фразу до 500 символов и нажать «Дать слово чудику».

Ключ хранится только на сервере, **без префикса `VITE_`**. Новый API работает в Vite dev и preview. Исходная интеграция Respeecher остаётся в старой лаборатории.

Для TTS используется `eleven_multilingual_v2`. Аудио декодируется Web Audio API; средняя амплитуда управляет челюстью и раскрытием рта. Это базовая синхронизация по громкости, не фонемный липсинк. Демо использует системный голос браузера, доступность которого зависит от браузера/ОС; движение рта в демо приблизительное. Переключение персонажа отменяет текущую речь и ожидающий запрос.

Контракт реализован по официальным API: [Voice Design](https://elevenlabs.io/docs/api-reference/text-to-voice/design), [сохранение голоса](https://elevenlabs.io/docs/api-reference/text-to-voice/create), [Text to Speech](https://elevenlabs.io/docs/api-reference/text-to-speech/convert). Без ключа выполнены проверки контракта с подменённым upstream; реальные запросы ElevenLabs и качество сгенерированного голоса ещё требуют проверки после подключения аккаунта.

## Структура

- `src/bulala/genome.ts` — версия ДНК, валидация, RNG, каталоги, вероятности, характер.
- `src/bulala/creature.ts` — геометрия, материалы, мех, анимация и освобождение ресурсов.
- `src/bulala/stage.ts` — Three.js, свет, камера, адаптация кадра, управление и снимки.
- `src/bulala/voice.ts` — воспроизведение, отмена, аудиоанализ и демоголос.
- `src/bulala/main.ts` и `style.css` — мастерская, настройки, коллекция, ДНК и экспорт.
- `vite-plugins/bulala-voice.ts` — серверный прокси, Voice Design, привязка голосов, лимиты запросов.

## Границы прототипа

Это локальный MVP без аккаунтов, общей базы коллекций и публичного размещения. Для публичного сервиса голосовые маршруты нужно перенести в отдельный backend с авторизацией, квотами на пользователя и постоянным хранилищем; простой статический хостинг не исполняет Vite-плагины. Стиль процедурный, игрушечный; это не скульптурные модели ручной работы. GLB-экспорт и фонемные blendshape-анимации пока не входят в MVP.


## Анатомия v3

Нос — локально уплотнённый параметрический участок общей сетки головы с общей границей и нормалями. Семейства включают кошачий, медвежий, тюлений и нос-лист. Вариант без носа воспроизводимо увеличивает главный глаз или рот. Уши — замкнутые раковины с общей кромкой передней и задней поверхностей. Рога имеют переменное сечение, изгиб и рельеф; хвосты — независимые вариации длины и изгиба.

Зрачки настраиваются отдельно: шесть контуров. Различие одного зрачка остаётся событием с вероятностью 5% исключительно для двух глаз. Старые v2 получают прежнюю базовую форму зрачка. Индекс помпона заменён коротким крючком; остальные старые индексы сохраняются. Голоса по-прежнему привязаны к seed. Уши, рога и хвосты используют практически равномерные целые веса (разница не больше одного процентного пункта).

Для визуальной проверки доступна локальная страница `/tests/anatomy-gallery.html`: одинаковая гладкая голова, все семейства и два ракурса. Изображения строятся последовательно; временные персонажи освобождают ресурсы. Эта страница не входит в production-сборку.
