# Булала · база, батлы и мастерская

Новая оболочка на Three.js находится на `/` с тремя вкладками: **База**, **Батлы**, **Мастерская**. Старый Pixi-прототип сохранён на `/legacy.html`.

## Запуск

```sh
npm install
npm run dev
```

Открыть http://127.0.0.1:5173 (или адрес, который напечатает Vite). Маршруты: `#/base`, `#/battles`, `#/workshop`.

```sh
npm test       # ДНК, геометрия, экономика, прожарка, батлы
npm run build
npm run preview
```

## Вкладки

### База (главная)

Минималистичный mobile-first экран: булала чуть выше центра. Зажми 1с — блобы вокруг **головы** (Sims radial-drag); взгляд и наклон тела следуют за наведённой кнопкой. Уход с FX (душ/пена, кормление, 3 варианта поглаживания); грязь/мухи/смрад при низких needs. Внизу — peek-коллекция с WebP-превью.

### Батлы

Полный оверлей-плеер: пипки раундов, гонг + карточка «РАУНД N», прожектор на спикера, караоке-субтитры, мик-дроп, голосование в шите. SFX через WebAudio (переключатель в шапке).

### Мастерская

Существо на весь экран + нижний шит без вложенных скроллов: горизонтальная snap-лента вариантов, ←/→ и кнопки prev/next, живой превью на hover.

## Экономика (прототип, localStorage)

Все числа живут в одном месте — `src/bulala/game/economy.ts`. UI и этот текст читают их оттуда, чтобы не расходились.

### Две валюты

| | Хайп ⚡ | Реп 🏆 |
| --- | --- | --- |
| Простыми словами | монетки | слава |
| Где хранится | на аккаунте (`save.hype`) | на каждом существе (`creature.rep`) |
| Тратится | да — на боксы | никогда, только копится |
| Зачем | покупать боксы | титулы, рейтинг, будущая косметика |

### Откуда берётся хайп

| Действие | Хайп | Заметки |
| --- | --- | --- |
| Победа в батле | `+60 × k` | `WIN_HYPE` |
| Проигрыш в батле | `+15 × k` | `LOSS_HYPE` — утешительные |
| Голос за чужой батл | `+5` | `VOTE_HYPE`, до 10 голосов в сутки → максимум +50 |
| Полный уход за день (покормил + помыл + поговорил) | `+25` | `CARE_DAILY_HYPE`, один раз в сутки, плюс энергия до максимума |
| Открытие бокса | `−1000` | `BOX_HYPE_COST`, цена настраивается игроком |

Старт: `STARTER_HYPE = 1200` — ровно на первый бокс и немного сверху.

### Откуда берётся реп

| Действие | Реп |
| --- | --- |
| Победа | `+40 × k` (`WIN_REP`) |
| Проигрыш | `+8 × k` (`LOSS_REP`) |

Титулы (`REP_TIERS`): Новичок 0 → Уличный 250 → Известный 750 → Легенда квартала 2000 → Король базы 5000.

### Коэффициент соперника `k` (антифарм)

```
k = clamp(0.4 + (репСоперника + 200) / (мойРеп + 200) × 0.6, 0.4, 1.6)
```

По-детски: бьёшь сильного — платят больше (до ×1.6), обижаешь слабого — платят меньше (до ×0.4). Пример: мой реп 1000, соперник 1500 → `k ≈ 1.05` → победа даёт 63 хайпа и 42 репа.

### Энергия и лимиты

- `MAX_ENERGY = 3`; батл тратит 1, любое дело ухода даёт +1.
- `FREE_BATTLES_PER_DAY = 3` — столько батлов в сутки можно даже без энергии.
- `DAILY_VOTE_LIMIT = 10` голосов в сутки.
- Хранится максимум `MAX_BATTLES_STORED = 30` батлов и `MAX_CREATURES = 48` существ.

### Затухание нужд (`game/care.ts`)

Нужды не тикают таймером — считаются из времени последнего действия по half-life: еда 18 ч, душ 24 ч, вайб 12 ч. То есть за 18 часов сытость падает вдвое.

### Ручная настройка (прототип)

Тап по чипу ⚡ в шапке открывает «Хайп и цены»: можно вручную выставить свой хайп (`setHype`) и цену бокса (`setBoxCost`, `0…999999`, `0` = бесплатно). Значения нормализуются (`normalizeHype` / `normalizeBoxCost`) и кладутся в сейв (`save.boxCost`), поэтому переживают перезагрузку. В той же модалке лежит детский разбор математики очков.

Ещё ручные оверрайды на Базе: тап по кружку нужды — уровень 0–100, тап по чипу репа — значение репа.

## Бокс и появление

Анимация `fx/reveal.ts`: левитирующая капсула → 3 тапа с SVG-трещинами и световым пробоем → спалах/ударная волна → пружинная поява с буквами имени и лентой редкости. Пока капсула живёт, воркер уже строит меш.

## Данные

- `localStorage` ключ `bulala-save-v1` — JSON сейва (существа без PNG, батлы, хайп, страна, голоса).
- IndexedDB `bulala-media-v1` — WebP-превью 192px и кеш TTS MP3.
- Старый `bulala-collection-v1` мигрируется один раз при первом запуске (геномы сохраняются).

## ElevenLabs

В `.env.local`:

```dotenv
ELEVENLABS_API_KEY=sk_...
ELEVENLABS_VOICE_ID=optional_default
```

Провайдер для батлов запоминается в `localStorage` (`bulala-tts-provider`). Кеш аудио: `game/tts-cache.ts` (память LRU + IndexedDB), префетч следующего бара во время текущего.

## Структура (новое)

- `src/bulala/app/` — shell, router, sheet, base, battles, workshop, battle-stage, collection-sheet, wallet
- `src/bulala/game/` — state, store, economy, care, battle, roast, ranking, tts-cache
- `src/bulala/fx/` — radial, reveal, care-fx, needs-fx, sfx, geometry, needs-map
- `src/bulala/stage-core.ts` — общая Three-сцена + framing
- `src/bulala/style/` — tokens, atoms, shell, sheet, base-screen, workshop, battles, reveal, fx, wallet

Легаси `style.css` больше не импортируется (конфликтовал с layout). Генератор (`genome`, `creature` геометрия, `morphology`, …) по контракту ДНК не менялся; у creature/motion добавлены только `attention` и реакции `shiver`/`chew`.

## Границы прототипа

- Нет реальной оплаты, аккаунтов и серверного рейтинга.
- Голоса, реп и топ стран живут в браузере и легко подделываются через DevTools.
- Оппоненты батлов — боты с фиксированных seed + другие свои булалы.
- Vite-плагин голоса работает в `dev` / `preview`, не на голом статическом хостинге.
- Косметика за реп — заглушка (слоты в модели данных есть).
